# English Verb Forms Trainer

Interaktive React-Lernapp zum Üben englischer Verbformen mit direkter Korrektur und zufällig generierten Aufgaben.

## Lokal starten

```bash
npm install
npm run dev
```

## Für Vercel

Vercel erkennt das Projekt automatisch als Vite/React-Projekt.

- Build Command: `npm run build`
- Output Directory: `dist`
